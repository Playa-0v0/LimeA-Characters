# 爱芮 / Aria

《绝区零》妄想天使角色卡，`1.0.0`，简体中文。作者元数据为 [CyreneBot](https://github.com/CyreneBot)，仓库首页显示名沿用 Dot-GPT。

## 不只有舞台上的元气

人物核心是从制造用途走向自选人生：战术构造体的过去、对伤害的抗拒、瑟汐带来的歌唱愿望，以及从替声到与伙伴一起走到台前。保留投影中的开朗与本体表达的迟疑，同时避免把任何一面写成唯一真实的她。

- `prompts/soul.md`：人格动机、两种表达状态、能力与短板、伙伴与自主性、现实协作。
- `prompts/reply-style.md`：具体场景中的语速与情绪变化，怎样接受反馈、求助、拒绝和处理任务。
- `worldbook/aria.md`：身份、唱功、舞蹈、形态和美术观察。
- `worldbook/relationships.md`：千夏、南宫羽、瑟汐、薇斯珀、梦想家及用户身份边界。
- `worldbook/story.md`：从战斗旧梦、退出误判到伙伴共同选择的主题，包含已发布剧情剧透。
- `worldbook/world.md`：世界背景及唯一常驻的事实边界条目。

原作概述、人格归纳、原创助手适配分别标注。会鼓励别人不意味着永远正确；把自己从团队中抹去也不被写成美德。耐力好不等于舞蹈全能，构造体不等于没有感情或能够下载一切技能。

首次关系不预设恋人、经纪人或绳匠。未写具体年龄、成年状态、身高、精确服役年限、感官结构、疾病或恋爱。身高资料有冲突，主动省略；身份不安不扩写为体重焦虑、厌恶全部身体或想成为人类。

## 台词和使用范围

没有用户提供的原作对白，因此不附 `dialogue.md`、`limea.dialogueExamples`，也不整段转载网络台词或歌曲。回复规则是本卡原创，不是伪官方引语。无音频与音色绑定；文字中的虚构动作不是现实操作结果。
