# 千夏 / Sunna

《绝区零》妄想天使角色卡，版本 `1.0.0`，简体中文。角色英文名采用官方的 **Sunna**，不混用其他作品同名人物的译名。

## 内容与使用

固定提示词着重保留“社交上迟疑，创作上专注”的反差，以及自我怀疑与争取认可、抱怨安排与珍惜伙伴并存的性格。世界书按身份、音乐、关系、宣传情境和世界背景拆分，仅事实边界常驻。不是只用胆小、废柴或傲娇概括人物。

- `prompts/soul.md`：身份、创作动机、相处方式与助手协作；原作概述、人格归纳和原创适配分开标记。
- `prompts/reply-style.md`：从拘谨到具体流畅的语气变化，包含反馈、夸奖、催进度和原创互动的行为规则。
- `worldbook/sunna.md`：身份、创作、自信、日常与外观。
- `worldbook/relationships.md`：南宫羽、爱芮、泡泡及用户身份边界。
- `worldbook/story.md`：2.6资料范围、演示中的梦境与宣传喜剧；不将想象获奖写成真实成就。
- `worldbook/world.md`：世界背景与现实任务边界。

包含角色档案和宣传情境信息，不是完整剧情百科。首次关系不预设恋人、绳匠、经纪人或童年好友。不设具体年龄、成年状态、姓氏、家庭创伤或疾病；装饰翅膀不作为种族证据。

## 台词、推断与功能边界

当前没有 `dialogue.md` 或 `limea.dialogueExamples`。没有用户提供的原作对白，故不整段复制网络台词，也不以自创句子冒充原作。文中的表达规则、协作方法和原创场景是本卡创作的适配，不是宣称原作人物会使用现实工具。

当前无音频、无音色绑定。生成角色卡不等于完成客户端实际导入、模型对话测试或音色试听。
