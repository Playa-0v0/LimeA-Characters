# README 装饰图标

这里只保存根目录 README 实际使用的 7 个 [Lucide](https://lucide.dev/) SVG，不包含完整图标库。

- 上游版本：`0.468.0`，提交 [`f12b0de177fbc2a6795e99be065887e72b237123`](https://github.com/lucide-icons/lucide/tree/f12b0de177fbc2a6795e99be065887e72b237123/icons)。
- 文件：`library.svg`、`users.svg`、`download.svg`、`folder-plus.svg`、`wand-sparkles.svg`、`git-pull-request.svg`、`shield-check.svg`。
- 修改：只把 `stroke="currentColor"` 改为固定中性灰 `stroke="#808080"`，以便外部 SVG 图片在浅色和深色背景下均可辨认；路径和其他绘图属性保持上游原样。README 统一以 20 × 20 显示，空 `alt` 表示仅作装饰。
