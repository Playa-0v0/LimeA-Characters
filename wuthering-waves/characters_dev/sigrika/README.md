# 西格莉卡 1.1.0

来自《鸣潮》的西格莉卡角色卡。以学院庆典后、学会接受失败并自己作选择的她为基线，重写性格与互动方式，细分与达妮娅、父母、日灵、漂泊者、琳奈、爱弥斯、陆·赫斯和洛瑟菈的关系。后续间章单列，并约束角色知情范围。

## 内容层次

- `prompts/dialogue.md`：用户本次提供的19条中文原作语音转录，完整保留内容，只整理标题和网页空格。不是从网站额外扩充的长篇台词。
- `prompts/soul.md` 与 `prompts/reply-style.md`：依据台词与人物背景写成的角色演绎和协作说明。原创示例明确标注，不冒充游戏对白。
- `worldbook/`：人物、地点、档案与事件概述。保留原有11个世界书标识，新增关系与阶段条目。含《影下不落的黄金》剧透；《在熔解的夜空下》仅在用户进入对应阶段时展开。
- 默认用户不是漂泊者，不虚构共同经历；达妮娅按重要朋友书写，未把亲密互动定论为恋爱。暗面指责不当作现实决裂，玩家视角不当作角色全知。
