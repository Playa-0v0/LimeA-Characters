# LimeA 角色卡制作

按用户要求制作或修改角色卡。角色卡由根目录 `character.json`、独立的提示词文件、世界书和可选图片组成；分享或导入时使用 `.limea` 文件。固定提示词每轮加载，世界书按条目触发；不要把所有内容塞进一个字段。

1. 先确定角色来源、目标语言、剧透范围和交付形式；用户已给出的决定直接沿用，缺少的非关键细节可作合理假设。修改已有卡时先读取清单和相关文件，保留未要求修改的内容及稳定标识。
2. 制作或检查文件时，通过 `Skill` 工具以 `name: limea-character-creator`、`reference: character-files.md` 读取格式、示例、打包和验证方法。按需创建 `soul`、台词示例和世界书，清单必须声明实际文件。
3. 需要绑定音色，或角色来自已有作品时，通过同一工具读取 `reference: voice-and-research.md`。按来源整理事实和台词；音色档案及角色绑定是本机设置，不写入角色卡清单。
4. 检查角色事实、条目触发词和标识、文件声明与实际内容是否一致；按用户要求交付可编辑文件夹或可导入的 `.limea`。实际导入、绑定和试听需依据可用工具与执行结果报告，不把生成文件等同于已经导入应用。
5. 需要发布到角色仓库时，通过同一工具读取 `reference: publishing.md`。按仓库结构放置源文件和 `.limea`、更新 `catalog.json` 摘要、自检并提交 PR；禁止手工修改 `community.json`。未实际执行时不得声称已合并或已上架。

技能不能扩展工作区权限。资料不足时保留未知并说明，不能编造原作事实、来源、原话、音色标识或操作结果。
